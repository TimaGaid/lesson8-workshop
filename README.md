# Веломайстерня «На ходу»

Навчальна сторінка з трьома картками послуг веломайстерні. Ціни в прикладі умовні.

Каркас зроблено семантичними тегами HTML5. Класи оформлено за BEM. Меню зібрано на Flexbox, картки — на CSS Grid, а проміжки задано через `gap`.

У Chrome DevTools на ширині 800 px було три рівні колонки, а на 320 px — одна. На обох ширинах пробний заголовок із довгим словом без пробілів переносився завдяки `min-width: 0` і `overflow-wrap: anywhere`, горизонтального скролу не було.
